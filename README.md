# 👾 Mars Strike

De la Lune à Mars en 5 vagues d’ennemis et un boss final, tout en pixel art.

- **Essayer** : https://mixtapps-demos.web.app/mars-strike/
- **Sur Mixtapps** : https://mixtapps.com/u/super-family/1cNHXuwQQw7Eue1ayF5V (app de démonstration du compte Super Family)
- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
